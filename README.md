🚀 Personal Portfolio Web Application

Modern ve yönetilebilir bir Kişisel Portfolyo Web Uygulaması. Proje, ziyaretçilerin görüntülediği dinamik bir portfolyo sitesi ve içeriklerin yönetilebildiği kapsamlı bir Admin Panelinden oluşmaktadır.

✨ Features
Dynamic Single Page Portfolio
Admin Dashboard
Authentication & Authorization
Full CRUD Operations
Contact Message Management
Testimonial Approval System
Project & Technology (Many-to-Many) Relationship
Responsive Design
Dashboard Statistics
🛠️ Technologies
ASP.NET Core 8.0 MVC
Entity Framework Core (Code First)
MS SQL Server
Razor Views
View Components
Cookie Authentication
Tailwind CSS
JavaScript (Fetch API / AJAX)
SweetAlert2
